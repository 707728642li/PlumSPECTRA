
# Availability plan

At submission, the three repositories remain private. Review access can be granted by
the corresponding author or through the journal. After acceptance and rights review:

1. make the code repository public at an immutable release commit;
2. archive the code release and analysis-ready dataset as separate DOI records;
3. publish final 12-trait deployment weights only after serialized replay succeeds;
4. cite version-specific DOI records in the article;
5. retain raw instrument exports under controlled access if redistribution is not approved.
